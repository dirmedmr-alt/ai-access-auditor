# Security

## Reporting a vulnerability

Please report security problems privately: on this repository, open **Security → Report a vulnerability**. Don't open a public issue.

Include what you found, how to reproduce it, and which version and system you use. You'll get an answer as soon as possible, and a fix in the next release.

## Supported versions

Only the latest release gets security fixes. The app tells you when a new version is out.
